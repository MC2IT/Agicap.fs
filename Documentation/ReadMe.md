# Agicap for F#
An [Agicap](https://agicap.com) API client library for [F#](https://learn.microsoft.com/en-us/dotnet/fsharp).
	
## Quick start
Install the latest version of **Agicap for F#** with [NuGet](https://www.nuget.org) package manager:

```powershell
dotnet package add Mc2it.Agicap.FSharp
```

For detailed instructions, see the [installation guide](Installation.md).
